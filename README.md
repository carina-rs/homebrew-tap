# homebrew-tap

[Homebrew](https://brew.sh/) tap for [Carina](https://github.com/carina-rs/carina).

## Install

```console
$ brew install carina-rs/tap/carina
```

This installs the `carina` CLI and the `carina-lsp` language server.

## Upgrade

```console
$ brew upgrade carina
```

## How the formula is updated

[`Formula/carina.rb`](Formula/carina.rb) is generated by the release workflow in the carina repository and pushed here on every release. Do not edit it by hand; change the template in the carina repository instead.
